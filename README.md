# Motorola Sales Analysis Dashboard

An interactive Power BI dashboard designed to analyze Motorola
sales performance across products, cities, payment methods,
customer ratings, and time periods.

## Dashboard Preview

![Motorola Sales Dashboard](screenshots/dashboard.png)

## Key Metrics

- Total Sales: 769M
- Total Quantity: 19K
- Transactions: 4K
- Average: 40K

## Dashboard Features

- Product-wise sales analysis
- Monthly sales analysis
- Yearly and quarterly sales trends
- City-wise sales analysis
- Payment method analysis
- Customer rating analysis
- Interactive month filters
- KPI cards
- Data visualization

## Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
- Data Analysis
